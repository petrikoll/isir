ISIR Kontrola

Instalace ulozi aplikaci do:
%LOCALAPPDATA%\ISIR-Kontrola

Data se pri instalaci neprenaseji.
Pri kazde nove instalaci se smaze stara databaze i stazene dokumenty.
Po prvnim spusteni si aplikace vytvori prazdnou slozku data a prazdnou databazi.

Odinstalaci najdete ve Start menu jako:
Odinstalovat ISIR Kontrola

Vymazani dat bez odinstalace najdete ve Start menu jako:
Vymazat data ISIR Kontrola
